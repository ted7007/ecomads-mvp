# Golos Text

The three WOFF2 files are the unchanged embedded Cyrillic, Latin Extended and
Latin subsets from the approved EcomAds web interface v10 HTML mockup.
The original weight declarations (400, 500, 600, 700, 800) and Unicode ranges
are retained in `golos-text.css`. The unbundled remote Cyrillic Extended subset
is not requested by the application.

Only the CSS family alias is changed to `EcomAds Golos Text`. This isolates the
workspace font from the existing login theme; the font binaries are unchanged.
