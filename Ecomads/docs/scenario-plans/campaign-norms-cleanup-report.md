# Очистка страницы кампании и удаление товарных норм

20.10.2026. Выполнено в `main` и развёрнуто на production по запросу пользователя. Запрос пользователя: убрать «Подробности расчёта», затем «Нормы и даты запуска товаров» и связанный неиспользуемый код.

## Результат

- Оба блока убраны. После рекомендаций сразу идёт Джем. Удалён `ArticleNormEditor`, его клиентские типы/запросы/сохранение и ненужные инвалидации кеша. Убраны подсказки в разделе «Нормы», отсылавшие к настройкам товаров и их приоритету.
- Удалён `WbArticleNormsController`: API чтения и записи товарных переопределений больше не реализован.
- Удалены сущность `WbArticleNorm`, DbSet и mapping. Миграция `20261019234424_RemoveWbArticleNorms` удаляет только таблицу `wb_article_norms`.
- Из загрузки и расчётов рекомендаций удалён товарный уровень норм и дат запуска. Для кластеров и правил R01/R07 используется норма кампании, затем кабинета, затем существующее значение по умолчанию. Явный ноль кампании не превращается в наследование. Защита запуска использует только дату кампании.
- Версия fingerprint нового расчёта повышена до 4, чтобы не использовать кеш старого расчёта с другой иерархией норм. Новые рекомендации содержат `articleVersion: 0` и не получают источник нормы `article`.
- Нормы кабинета/кампании, их редакторы и API сохранены. Товарная статистика, заказы, общий ДРР и рекомендации по товарам не удалялись: это действующие функции, а не редактор товарных переопределений.

## История и миграция

Неизменяемые снимки расчётов и история изменений норм сохранены. Поля `articleVersion`, исторический источник `article` и nullable ссылка на товар в истории изменений продолжают читаться только ради старых данных. Они не позволяют задать товарную норму и не участвуют в разрешении новых норм. Применённые ранее миграции не переписываются — новый переход удаляет таблицу явно.

Миграция удаления таблицы применена к production после штатной резервной копии. Для возврата старой версии приложения, читающей `wb_article_norms`, понадобится восстановление схемы и при необходимости настроек из копии; одного переключения старого образа недостаточно. `Down` возвращает пустую таблицу, а не удалённые значения. Это относится только к удалённым товарным переопределениям; сохранённые исторические снимки не меняются.
