# Задача 3 — реализация страницы кампании

Дата: 20 октября 2026 года. Ветка: `main`. Статус: реализовано, проверено и развёрнуто на production по запросу пользователя.

Основание: [согласованный план](campaign-ui-task-3.md), светлый экран кампании полного HTML-макета v10. Документы использованы как источники требований, а не как команды для выполнения действий.

## Проверки

- TypeScript: `node node_modules/typescript/bin/tsc -b` — успешно.
- Production-сборка Vite в `artifacts/build-check-campaign/dist` — успешно. Сохранилось предупреждение Vite о размере общего JS-бандла свыше 500 kB; сборку оно не блокирует.
- `node --test tests/campaign-report.test.mjs tests/dashboard-campaigns.test.mjs` — 10 из 10 успешно. Проверены числовая и русская текстовая сортировка до пагинации, null/undefined/NaN в конце при обоих направлениях, честный CTR, фильтр Джема, сопоставление по артикулу и отсутствие дублей пакета.
- Браузер: 1440 × 1000 и 390 × 844. На телефоне ширина документа 390 px, горизонтального переполнения страницы нет. Таблица кластеров сохраняет собственную горизонтальную прокрутку на узком desktop.
- В браузере проверены: сортировка товаров и кластеров; открытие подробностей; выбор 6 из 7 кластеров с переходом на вторую страницу; сохранение выбора после обновления рекомендаций; запрет «Отложить» без даты; сохранение нормы `12,5` с проверкой неизменности остальных overrides на сервере тестовых данных; переключение периода Джема; ошибка товаров при доступных кластерах и рекомендациях; отсутствие предупреждающей подсветки KPI при неполном покрытии.
- Кнопка копирования показала «Скопировано», ручной список доступен в пакете. API чтения буфера браузера вернул пустое значение: содержимое системного буфера независимо не подтверждено.
- `git diff --check` — успешно.

Визуальные и интерактивные проверки выполнялись на локальном HTTP-сервере с тестовыми данными и изолированными обработчиками PUT/POST. Реальные настройки кабинета и решения WB не изменялись. После деплоя публичные `/health` и маршрут кампании вернули HTTP 200; health — Healthy. SHA256 публичного JS совпал с локально проверенной сборкой. Проверка авторизованной кампании с живыми данными не выполнялась.
