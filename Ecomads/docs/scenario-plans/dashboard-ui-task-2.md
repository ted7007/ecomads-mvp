# Задача 2 — сводка по светлому макету v10

Реализовано 19 октября 2026 года в основной рабочей копии `main`. Общие светлые токены взяты из завершённой первой задачи.

## Изменения

- «Требуют внимания»: отдельные карточки, три в ряд на широком экране и одна на телефоне; показатель, норма, действие и решения видны сразу, основания раскрываются. Период рекомендаций остаётся фиксированным 14-дневным. Статус «Принято» не означает применение в WB.
- Актуальность: карточка в боковой панели сводки, краткая строка на телефоне, предупреждения о неполных источниках и сроке токена. Последняя успешная загрузка рекламы берётся из `lastSyncAt`; `lastCheckedAtUtc` обозначает только проверку источника. При нескольких кабинетах показана самая ранняя успешная загрузка, только если время известно для каждого.
- Таблица: сортировка восьми колонок до пагинации; неопределённые значения всегда в конце, стабильное сравнение по ID, сброс страницы при изменении сортировки/периода. ДРР и CTR подсвечиваются относительно своих норм только при полном покрытии.
- На телефоне: статус кампании под названием, ДРР справа, явное направление сортировки, компактные стрелки пагинации. Четыре основных KPI занимают сетку 2×2, CTR доступен в раскрытии.
- Периоды сводки: 7/14/30 дней и свой период; сегодня и год сохранены в дополнительном выборе.
- Без кабинета и кампаний сразу показана одна карточка подключения. При подключённом кабинете пустая таблица предлагает проверить загрузку.

Общие компоненты получили необязательные параметры; существующие режимы страницы кампании сохранены. Серверные API, расчёты, светлые токены первой задачи, legacy `wwwroot`, эффект и тёмная тема не менялись.

## Проверка

Из `Ecomads.WebApplication/ClientApp`:

```powershell
node node_modules/typescript/bin/tsc -b
node --test tests/dashboard-campaigns.test.mjs
node node_modules/vite/bin/vite.js build --outDir ../../artifacts/build-check-dashboard/dist --emptyOutDir false
```

- TypeScript и production-сборка прошли. Vite предупреждает о размере общего JS-чанка; разделение чанка не входит в эту задачу.
- Пять тестов: числовая сортировка до пагинации, пропуски и нули, достаточность данных для сравнения, отрицательные изменения и стабильное равенство, русский алфавит.
- В браузере проверены desktop 1440 px и телефон 390 px на изолированных тестовых ответах существующих API. Настоящий backend, база и WB API в этой проверке не использовались.
- Проверены сортировка CTR, вторая страница и сброс сортировкой, сохранение решения с обновлением карточки, отсутствие горизонтального переполнения на телефоне, состояние без отклонений, неполная загрузка и отсутствие кабинета.
- Снимки находятся локально в `artifacts/build-check-dashboard`: `desktop-summary.png`, `mobile-summary.png`, `mobile-campaigns.png`. Это тестовые данные, не показатели реального кабинета.
