# Задача 01 Общие стили светлого интерфейса

Реализована единая светлая тема рабочего интерфейса по макету EcomAds v10.
Тема подключена внутри AppLayout; корневая тема и экран входа сохранены.
Рабочая ветка: `codex/light-ui-foundation`.

## Изменения

- Единый объект `lightUiTokens` задаёт фон, поверхности, границы, текст, статусы,
  Джем, радиусы, тени и фокус. Обычные панели остаются полупрозрачными белыми.
- Градиенты, sidebar 240 px и отступы 40/28 px на desktop соответствуют эталону.
  Мобильный Drawer сохраняет поведение и имеет светлую подложку под размытие.
- Три встроенных WOFF2-подмножества Golos Text извлечены из согласованного HTML.
  Сохранены исходные диапазоны и объявления весов 400–800. CSS-семейство
  `EcomAds Golos Text` применяется только в рабочем интерфейсе. Лицензия рядом.
- Унифицированы карточки, KPI, кнопки, поля, таблицы, сообщения, метки,
  всплывающие меню, диалоги и пагинация. Цвета метрик графика сохранены.
- Общий заголовок больше не добавляет лишний нижний отступ. Кнопка действия
  в desktop-шапке не растягивается по высоте описания.
- Убраны конфликтующие локальные размеры заголовков; обе таблицы Джема
  используют общие цветовые токены.
- Метка «Выше цели» перенесена под числовое значение внутри той же ячейки,
  чтобы не перекрывать соседнюю колонку при новом шрифте.

Состав блоков, колонки, фильтры, сортировки, API, обработчики и расчёты сохранены.
Эффект, виджеты экономии, тёмная тема и legacy-файлы не изменялись.

## Проверка

Проверены реальные общие компоненты в изолированном представлении с явно
обозначенными тестовыми данными. Использовались AppLayout, Sidebar, PageHeader,
KpiCard/KpiGrid, DailyChart, CampaignsTable, NomenclatureTable, WbJamTable,
PeriodFilter, PaginationBar и элементы MUI. Это **не полная проверка
авторизованных страниц**: backend и рабочие данные WB для неё не подключались.

Проверены четыре представления на 1440×1000 и 390×844: сводка, кампания,
формы норм, кабинет/Telegram. Проверены крупная сумма и длинное название,
обычное/выбранное/недоступное/ошибочное состояния, фокус с клавиатуры,
переключение KPI, переход на вторую страницу, выбор в выпадающем меню,
ввод числа, открытие и закрытие Drawer клавишей Escape.

На обоих размерах нет горизонтального переполнения документа и main.
Горизонтальная прокрутка широких таблиц и существующего фильтра периода
остаётся внутри своих контейнеров. Фон сохраняется внизу длинной страницы,
мобильная шапка не перекрывает начало содержимого. Заголовок имеет 28/22 px;
браузер подтвердил использование `EcomAds Golos Text`. Desktop-кнопка
сохранения имеет высоту 36 px, клавиатурный фокус — рамку 2 px.

Снимки входа до/после отличаются только небольшим участком автофокуса Email;
изменений темы или разметки входа нет. Для браузеров без backdrop-filter
предусмотрен непрозрачный светлый фон; этот режим проверен по CSS,
без отдельной эмуляции браузера.

TypeScript и production-сборка Vite проходят. Вывод сборки направлен в
`artifacts/build-check-light-ui/dist`, поэтому `wwwroot` не перезаписывается.
Vite сообщает о размере основного JS-чанка больше 500 kB; разделение чанков
в эту задачу не входит. `git diff --check` проходит.
