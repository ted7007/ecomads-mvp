# Расход сводки при неполном месяце

20 октября 2026. По сообщению пользователя KPI расхода за месяц показывал прочерк и «Ожидаем историю затрат WB».

## Причина

В истории за 20 сентября — 19 октября есть сохранённые расходы, но 25 сентября источник имеет состояние `no_operations`: WB вернул историю без операций. Старые 0 ₽ сохранены в БД, однако такой ответ не доказывает явный нулевой расход. Проверка качества исключает этот день из подтверждённых. Карточка требовала наличия расхода за каждый день и из-за одного пропуска скрывала все 30 дней.

Расходы не удалялись. Неизвестный день не превращён в ноль, исходные записи и правила приёма WB не менялись.

## Исправление

Карточка суммирует подтверждённые дни источника истории затрат. При неполном покрытии показывает сумму с пометкой «Предварительно · N из M дней» и перечнем неподтверждённых дат в подсказке. При отсутствии всех подтверждённых дней остаётся прочерк с причиной. Сравнение с прошлым периодом разрешено только при полном покрытии обоих периодов равной длины. Загрузка остальных графиков больше не определяет доступность этого KPI.

Источник суммы остаётся прежним (`coverage.days[].spend`); суммы отдельных кампаний и неизвестные нули для замены не используются.
