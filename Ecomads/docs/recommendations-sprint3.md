## Расчёт

- Контракт 3. Текущее экономическое окно: D−15…D−2 по МСК, ровно 14 календарных дней. Даты запроса отчёта больше не определяют рекомендации.
- Предыдущие 14 дней используются только для сравнительной диагностики. Цена каждого окна считается отдельно.
- Отчётная таблица получает строки из собственного API выбранного периода. Метки рекомендаций сопоставляются по кампании, артикулу и имени кластера и подписаны как 14-дневные.
- № 1 использует все заказанные единицы за 14 дней и расход за три завершённых дня. № 2 — рекламу за семь завершённых дней и текущий бюджет. № 7 — фактическую рекламную сумму заказов товара за 14 дней, минимум три заказа O.
- Точная ставка не выводится без подтверждённых минимума и шага. Подтверждённые `nm_settings.bids_kopecks` определяют точечное управление товаром. Если область общей ставки неизвестна, снижение общей ставки не предлагается: карточка объясняет ограничение. Решение «Принял» не заменяет фактическое исключение в WB.
- Нет автоматических изменений кампаний WB.

## Источники WB

Официальные спецификации проверены через зеркало WB, запросы приложения направляются на исходные домены `.ru`.

| Источник | Метод | Особенности |
| --- | --- | --- |
| FBW/FBO, базовый токен | `GET /api/v1/warehouse_remains`, затем status/download | Доступен базовому токену категории «Аналитика». Этапы и taskId сохраняются в БД; ожидания в памяти нет. Для количества берётся явный `Total in warehouses`, детализация складов сохраняется. Транзит и детализация повторно не суммируются. |
| FBW/FBO, расширенный доступ | `POST /api/analytics/v1/stocks-report/wb-warehouses` | Строка — размер/склад. `quantity` без транзита, постраничное получение. |
| FBS, текущий адаптер | `POST /api/analytics/v1/stocks-report/seller-warehouses` | По документации доступен персональному или сервисному токену. Обычный базовый токен этого доступа не имеет. Альтернативный адаптер «Маркетплейса» пока не подтверждён и не реализован. |
| Заказанные единицы | `POST /api/analytics/v3/sales-funnel/products` | Фиксированное окно, все товары, `statistic.selected.orderCount`; пагинация, контроль дублей и валюты. Отсутствующий товар не подменяется нулевым темпом. |
| Бюджеты | `POST /api/advert/v2/budget` | Пакеты до 50 кампаний, отдельное время снимка каждой кампании; пропущенная пара означает ошибку источника. |
| Общий баланс | `GET /adv/v1/balance` | `balance + net`; бонусы не считаются доступными для переноса в бюджет. |
| Состав/ставки | `GET /api/advert/v2/adverts` | Общий ограничитель с обычной загрузкой кампаний; успешное получение также обновляет обычный импорт. |

Остатки и бюджет действительны не более часа от начала получения. Незавершённая замена допускает использование предыдущего полного свежего снимка; ошибка получения отменяет такое использование. Ответ 204 не превращается в нулевой остаток.

Ссылки: [отчёт остатков и лимиты базового токена](https://dev.wildberries.cn/docs/openapi/reports), [аналитика и ограничения методов остатков](https://dev.wildberries.cn/docs/openapi/analytics), [типы токенов](https://dev.wildberries.ru/en/docs/openapi/api-information), [реклама и финансы](https://dev.wildberries.cn/docs/openapi/promotion).

**Отложено за пределы выпуска:** полноценная № 1 для обычных базовых токенов требует доступного адаптера FBS. Одного FBW недостаточно. До отдельного решения правило полностью выключено и не создаёт сообщений о нехватке данных. ID сервиса не требуется остальным правилам спринта. Использование персонального токена в облачном сервисе не предлагается.

Сохраняются снимки с решениями; для продавцов с решениями прежнего механизма история сохраняется консервативно целиком.
- Исходная статистика, настройки и подключения не удаляются. Очистка выполнена после проверенной резервной копии: удалено 596 старых расчётов без решений, сохранено 19 581.
