# Исправление общего статуса рекомендаций — 30.10.2026

## Изменение

Общий статус кампании теперь определяется выполненными правилами, а не только наличием строк поисковых кластеров. Полностью выполненная проверка бюджета без срабатывания и без поисковых кластеров получает `no_deviations` вместо `not_ready`.

Сообщение уточняет границу: отклонений нет по выполненным проверкам; кластерные правила без поисковых кластеров не оценивались. При действительно пропущенных проверках остаются `limited`/`not_ready`; подтверждённая пустая кластерная выборка сохраняет `empty`.

Условия правил, пороги, расчёт цены и действия не менялись. Новых элементов и изменений оформления нет. Старые снимки остаются неизменными; новая версия fingerprint создаёт актуальный расчёт со скорректированным статусом, сохраняя историю решений через существующий жизненный цикл.
