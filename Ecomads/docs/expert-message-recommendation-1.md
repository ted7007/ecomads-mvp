Рекомендацию № 1 «Реклама на заканчивающийся товар» отменяем

Она должна оценивать, на сколько дней хватит доступного остатка FBW/FBO + FBS по темпу заказанных единиц за 14 дней. При запасе меньше 7 дней — рекомендовать поставку и не усиливать рекламу; меньше 3 дней — снизить ставку или временно убрать товар из рекламы; при нулевом остатке и продолжающемся расходе — остановить рекламу товара.

Причина отмены — пока нет проверенной загрузки полного остатка по обеим схемам для используемого базового токена WB. Для FBW найден доступный отчёт. Однако выбранный аналитический метод FBS требует другого типа доступа, а альтернативный способ получения FBS ещё не реализован и не проверен. Отсутствие данных FBS нельзя считать нулевым остатком: расчёт только по FBW может ошибочно рекомендовать ограничить рекламу товара, который есть на FBS.

В текущем выпуске № 1 полностью отключена: без карточек, сообщений о нехватке данных для неё и фоновой загрузки её источников. Подготовленную логику сохраняем, но дальнейшую реализацию пока не планируем. Возврат к рекомендации потребует отдельного решения.

Остальная часть третьего спринта сохраняется: единый расчёт рекомендаций за 14 дней, № 2 по бюджету эффективной кампании и № 7 по высокому ДРР товара при единой ставке.
