# EcomAds MVP - Информация о проекте

## Обзор проекта
EcomAds (ИИ-маркетолог) — это веб-сервис аналитики с искусственным интеллектом для продавцов и маркетинговых агентств на маркетплейсе Wildberries. Сервис помогает пользователям отслеживать и оптимизировать рекламные кампании на платформе Wildberries, предоставляя ценные аналитические данные, рекомендации и оповещения для повышения эффективности рекламы.

## Бизнес-цели
- Сократить время на ежедневный мониторинг рекламы Wildberries минимум на 50%
- Помочь пользователям снизить ДРР (долю расходов на рекламу в выручке) на 10-20% в течение 30 дней
- Предоставлять понятные алерты и рекомендации, которые пользователи реально применяют

## Целевая аудитория
- **Основная**: Маркетинговые агентства и фрилансеры-маркетологи, ведущие рекламу Wildberries для нескольких клиентов
- **Дополнительная**: Самостоятельные продавцы на Wildberries, которые управляют собственными рекламными кампаниями

## Ограничения MVP
- Нет автоматического изменения ставок/кампаний (только рекомендации)
- Нет полной интеграции с Ozon
- Нет сложного SEO-парсинга результатов поиска по ключевым словам
- Нет мобильного приложения
- Нет многопользовательских ролей/прав доступа (простая модель "владелец аккаунта")

## Функциональные модули

### Модуль A: Онбординг и настройка целей
- A1: Регистрация/вход (email/пароль или Telegram-логин)
- A2: Создание проекта (магазина)
- A3: Настройка целей (целевой ДРР, режим приоритета, пороги алертов)

### Модуль B: Импорт данных рекламы (ручной)
- B1: Источник данных (пользователь загружает CSV/XLSX отчеты из Wildberries)
- B2: Поддерживаемые сущности данных (кампании, даты, метрики, ключевые слова)
- B3: Валидация загрузки

### Модуль C: Дашборд и мониторинг
- C1: Главный дашборд (выбор периода времени, KPI-карточки, таблица кампаний)
- C2: Детальный просмотр кампании

### Модуль D: Триггеры и уведомления (Telegram)
- D1: Подключение Telegram
- D2: Триггеры алертов
- D3: Формат уведомлений

### Модуль E: Рекомендации
- E1: Логика рекомендаций на основе правил
- E2: Объяснение рекомендаций
- E3: Действия пользователя по рекомендациям

### Модуль F: Отчет "Эффект сервиса"
- F1: Автоматический отчет за период (обработанные алерты, принятые рекомендации, изменения ДРР, экономия времени)

## Нефункциональные требования
- Адаптивный веб-интерфейс (с приоритетом на десктоп)
- Производительность: загрузка дашборда до 3 секунд для периода 30 дней и до 500 кампаний
- Хранение данных: минимум 3 месяца истории
- Безопасность: надлежащая аутентификация, защита данных, безопасное хранение учетных данных
- Логирование: загрузки, ошибки, действия пользователей по рекомендациям

## Сущности данных
- User (Пользователь)
- Project (Проект/Магазин)
- Campaign (Кампания)
- CampaignDailyStats (Ежедневная статистика кампаний)
- KeywordStats (Статистика ключевых слов, опционально)
- Alert (Оповещение)
- Recommendation (Рекомендация)
- RecommendationAction (Действие по рекомендации)

## Метрики успеха
### Продуктовые метрики
- Активация: % пользователей, которые загрузили данные и просмотрели рекомендации
- Вовлеченность: DAU/WAU, количество просмотренных кампаний
- Ценность: снижение ДРР, % принятых рекомендаций, количество предотвращенных "сливов"

### Бизнес-метрики
- Конверсия в оплату после тестирования
- Удержание пользователей на 30 дней
- NPS/CSAT (оценка удовлетворенности пользователей)

## Критерии приемки
- Пользователи могут зарегистрироваться, создать проект и установить целевой ДРР
- Пользователи могут загружать отчеты Wildberries и просматривать кампании и метрики за выбранный период
- Сервис автоматически создает минимум 3 типа оповещений и отправляет их через Telegram
- Сервис формирует рекомендации по кампаниям/ключевым словам с объяснениями
- Пользователи могут отмечать рекомендации как принятые/отложенные/неактуальные и просматривать отчет "эффект сервиса"
